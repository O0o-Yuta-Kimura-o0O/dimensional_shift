## 採用した核

商を乗算方程式の解集合として定義する考え方を採用します。

`Q(a,b) = {x ∈ ℝ | bx = a}`

この定義から、`Q(0,0)=ℝ`、`a≠0` のとき `Q(a,0)=∅` が得られます。通常の実数の逆元として0の逆数を導入することはしません。ηを使う場合は `η(a)=Q(a,0)` という略記に限定します。

次元は点・直線・平面などの幾何学的な次元として扱います。本文の次元に関する一般的な主張は、非空アフィン空間など、次元を明確に定義できる対象に範囲を限定します。

## 変更・削除の理由

| 原メモの概念・記述 | 整理後の扱い | 理由 |
|---|---|---|
| `a={a}` | 数を単集合へ対応させる | 数と集合の型を区別するため |
| ηが計算式や引数を保存する | 集合値には保存を要求しない | 今回の著者の方針に従う。編集履歴の保存とは別問題 |
| 引数を取り出すηp系の関数 | 本文から削除 | 異なる非零の引数が同じ空集合に写るため、集合値だけからの復元は定義できない |
| `η(a)+η(b)=η(a+b)` などの形式変形 | 一般的な演算規則として採用しない | 同じ集合値から異なる結果が生じ、代入による等しさの保存と両立しない |
| `η(0)·η(0)=ℝ²` | 次元上昇には直積を使う | 実数値の積と独立な二座標の組は異なる |
| 0除算を重ねるだけで次元が増える | 採用しない | 集合値の合併による拡張では自由座標の数は自動では増えない |
| 除外集合と専用の四則演算 | 本文の基礎体系から削除 | 今回の次元操作に不要。必要なら補集合などとして別途定義できる |
| 多重集合・重複度による可視化 | 削除 | 解集合の定義と次元操作に不要 |
| 表裏の絶対値 | 削除 | 原稿の簡素化の目的から外れる |
| 不等式による次元下降 | 条件を明記して扱う | 領域を狭めても次元が下がるとは限らない |
| 偏差値・積分・音楽などの応用 | 本文から削除 | 基礎体系の検証と独立した課題であり、今回の主張の根拠にはしない |

## 演算で区別する事項

集合の二項演算で各要素を独立に選ぶことと、同じ変数を繰り返し使うことは区別します。例えば、`{x−x | x∈ℝ}={0}` ですが、`{x−y | x,y∈ℝ}=ℝ` です。独立性や変数の共有を、記法で明示します。

「演算を定義して計算を継続できること」から、通常の実数値関数としての連続性や、特異点を越える解析的な性質を結論しません。新規性や実用性についても、この整理のみから一般的な主張は行いません。
