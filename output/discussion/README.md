# 対話記録と論文版の対応

このフォルダは、論文の改稿に関係する対話を将来整理するための管理場所です。現時点では対話の全文エクスポートも公開も行っていません。GitHubリポジトリは非公開のまま管理します。

## 現在保存しているもの

`version_map.json` は、論文の版番号・Gitタグと、関連する話題の短い要約を対応させます。要約は逐語記録ではありません。`status: "not_exported"` と `transcript: null` は、対話本文をまだ書き出していないことを表します。`public: false` は公開していないことを示します。

## 将来、逐語記録を作るとき

- 取得できたユーザーとアシスタントの公開発言を、取得可能な範囲で逐語的に保存します。ここでいう公開発言は、ユーザーに表示された発言を意味し、システム指示、内部推論、秘密情報などを含みません。
- 取得元と範囲、欠落の有無を明記します。全範囲を確認できない場合は「全文」と呼びません。
- 実在を確認できないチャットID、発言、時刻を補いません。時刻や識別子が取得できなければ、その旨を記します。
- 原文の削除・伏字・表記修正・並べ替えを行った場合は、編集の種類と範囲を明示します。説明用の要約や編集者注は原文と区別します。
- 各記録を関連する論文の版番号・Gitタグに紐付け、後から対応を検証できるようにします。論文の一つの版が複数の対話に関係する場合も、その関係を明示します。
- 私的な情報、認証情報、機密情報、他者に関する情報を確認してから、保存・共有の範囲を決めます。

## 将来、公開するとき

公開する内容と公開先は、その作業時に確定します。現在の非公開リポジトリへの同期は、対話やリポジトリ全体を一般公開する指定ではありません。公開用に編集した記録と、非公開で保管する記録がある場合は、両者の違いを明示します。

公開が実施された後でのみ、対応表の公開状態と確認済みの公開先を更新します。論文タグとの対応は、対話の逐語性や取得範囲を保証するものではありません。
