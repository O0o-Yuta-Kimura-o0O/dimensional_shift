# 独立座標生成のビジュアライザー

論文 **v0.2.0** の `L_U(n,S)=(n+1,S×U)` を操作して確認する対話用ビジュアライザーです。著者表記は木村祐太・GPT-6 Astra（AI）です。

最新版：**visualizer-v0.2.0**。公開URLは https://dimensional-shift-l-visualizer.yummy-pig-6822.chatgpt.site です。

`coordinate-lift.html` は会話内の表示に使うHTMLフラグメントです。`export_site.py` で単独のWebページに書き出して配信します。公開URLでは最新版だけを提供します。GitHubでは過去のソースコードも公開し、閲覧サイトの版切り替えとは区別します。

## 操作と意味

- 「L を適用」で新しい独立座標を一つ追加します。既存座標をコピーして同じ値に拘束する操作ではありません。
- 「1回戻す」は最後のL適用を取り消します。商の逆演算や、論文で扱う一般の制約操作ではありません。
- 実数／離散格子を切り替えても、現在の座標数は維持します。
- 初期状態は `U⁰={()}`。0座標でも空集合ではなく、空の座標列を要素とする一点です。
- 描画領域をマウスでドラッグすると回転し、ホイールで拡大・縮小します。タッチでもドラッグして回転できます。
- 「−」「＋」でも倍率を変更でき、範囲は25〜500%です。「視点を戻す」で回転と倍率だけを初期状態へ戻します。
- 「視点を戻す」にキーボードのフォーカスを合わせ、矢印キーでも回転できます。
- 視点と倍率は操作状態として保存します。視点の変更は、独立座標数や格子点の組合せを変更しません。

実数の場合、全体は `ℝⁿ` であり、描画するのは各座標が `[-1,1]` に入る範囲です。非空実アフィン空間の次元はnです。格子の場合は `U={-1,0,1}` とし、全体は `3ⁿ` 点です。格子点を線分や面で補間しません。補助線は座標軸を示します。

## 投影と描画量

状態は必要に応じて伸びる座標列で保持し、各L適用時に新しい名前と投影方向を生成します。モデルに固定の最大座標数を設けていません。実際の実行にはブラウザーのメモリ・計算時間による制約があります。

最初の3座標は3D空間の標準基底に対応させます。4座標目以降も新しい独立座標を保持したまま、各座標の寄与を3Dへ線形投影し、回転・拡大縮小できる正投影カメラで画面へ写します。回転によって3Dへの投影方向自体を変更することはありません。3Dでの投影方向は、元の空間での独立性を表すものではありません。画面上の重なりや投影後の広がりから、元の空間の次元を判定しません。

実数モードでは、表示範囲の投影外形を厳密に計算します。6座標までは超立方体の辺も表示し、それ以降は外形を表示します。格子は6座標まで全点、7座標以上は729点の決定的な標本を描画します。標本はどの座標にも `-1,0,1` を含みますが、全組合せではありません。全体の `3ⁿ` と標本数は区別して表示します。

## 検証と再表示

数理モデルの検証は追加依存なしで実行できます。

```sh
node visualizer/test-model.cjs
```

会話内で表示する際は、フラグメントをそのまま読み込める可視化機能を使用します。Codexのvisualizeスキルを利用できる環境では、その `scripts/render.py` で確認用の一時ページを生成できます。生成先を `tmp/visualizer/preview.html` にした場合、Playwrightとその対応ブラウザーを利用できる環境で次を実行できます。

```sh
node visualizer/test-browser.cjs tmp/visualizer/preview.html
```

ブラウザーの実行ファイルを指定する場合は `LIFT_BROWSER_PATH` を設定します。テストは個人のブラウザープロファイルを使いません。回転・倍率・視点リセット、操作後の状態復元、キーボード、狭幅・ダーク表示、100座標までの連続操作、アニメーションも検証します。確認画像は `tmp/visualizer-v020/qa/` に生成され、Gitには含めません。

ビジュアライザーは論文とは別に版管理します。今回の追加によって論文原稿や確定版PDFは変更していません。

## ローカル履歴と公開

`history/<version>/` はローカルだけに保存する確定版のスナップショットです。既存の版は上書きしません。GitHub公開用のファイルには含めません。公開前の全Git履歴も `.local/backups/` に退避しています。

改訂時は `version.json` とこの変更履歴を更新し、検証済みの単独ページを用意してから、プロジェクトルートで次を実行します。

```sh
python3 scripts/snapshot_visualizer.py --version visualizer-v0.2.0 --site-index .local/visualizer-site/dist/index.html
```

版番号はその改訂で実際に使う新しい番号を指定してください。スナップショットにはソース、検証コード、単独ページ、SHA-256付きメタデータを保存します。Sitesの作業場所は `.local/visualizer-site/`、Site IDはその `.openai/hosting.json` を参照し、次回も同じ公開URLへ最新版を反映します。公開先の運用上の配信履歴と、ここで保管する旧版は区別します。ユーザーの明示的な指定により、GitHubのソース履歴と過去コードは公開します。公開サイトで旧版へ切り替える機能は設けません。
